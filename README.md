# GM6020 正弦曲线跟随

用 STM32 通过 CAN 总线控制 DJI GM6020 无刷电机，使其跟随**正弦波变化的速度曲线与位置曲线**，并使用**看门狗（IWDG）**进行程序保护。

---

## 1. 任务要求

- 用 GM6020 电机**分别**跟随：
  - 以正弦波变化的速度曲线（速度跟随）
  - 以正弦波变化的位置曲线（位置跟随）
  - 曲线可自定义（频率、幅值可配）
- 使用**看门狗**进行保护（配置中默认开启）
- 代码上传 GitHub，仓库设为 **public**

---

## 2. 实现思路

```
上位机/主控 ──CAN──> GM6020 电机
      │                   │
   下发目标(正弦)       内置速度环
      <── 反馈(角度/转速) ──┘

控制结构（速度跟随）：
    目标速度 ──► [速度环 PID] ──► 电压 ──► 电机 ──► 实际速度
                        ▲                              │
                        └────────── 反馈 ◄─────────────┘

控制结构（位置跟随，串级 PID）：
    目标角度 ──► [位置环 PID] ──► 目标速度 ──► [速度环 PID] ──► 电压 ──► 电机
                        ▲                                    ▲            │
                        └──── 实际角度 ◄────────────────────── 实际速度 ◄──┘
```

- **正弦轨迹生成**：`θ_ref(t) = A·sin(2πft + φ)`，其导数为速度目标 `ω_ref(t)`
- **前馈**：利用已知的目标速度/加速度做前馈，改善正弦跟随的相位滞后
- **看门狗**：IWDG，主循环定期喂狗；程序卡死时自动复位

## 4. 仿真说明（无需硬件）

仿真程序可直接在在线编译器运行，用来理解算法、预调参数。

**运行方式**：打开 https://www.onlinegdb.com/ ，把 `simulation/sim_gm6020.c` 整段粘进去，点 Run。

**参数说明**（改文件顶部的 `#define`）：

| 参数 | 含义 |
|------|------|
| `MODE` | 1=速度正弦跟随，2=位置正弦跟随，3=阶跃响应测试 |
| `FREQ` | 正弦频率（Hz），越高越难跟 |
| `AMP_SPEED` / `AMP_POS` | 速度 / 位置正弦幅值 |
| `V_KP/V_KI/V_KD` | 速度环 PID 参数 |
| `P_KP/P_KI/P_KD` | 位置环 PID 参数 |
| `FF_VEL` | 速度前馈强度（0~1） |

**已验证的规律**：

| 现象 | 结论 |
|------|------|
| 频率越高，跟随误差越大 | 控制系统存在带宽限制 |
| 增益太小 → 滞后大 | 比例增益的作用 |
| 积分过大 → 阶跃超调 | 跟得准 ≠ 稳得住 |
| 加前馈后误差大幅下降 | 前馈改善正弦跟随的关键 |
